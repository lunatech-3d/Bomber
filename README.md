# Build the Bombsight (Pygame Kiosk Prototype)

This is a standalone museum kiosk prototype intended as a separate mini-project.

## Run

```bash
python bomber/build_the_bombsight.py
```

## Controls
- Drag parts with mouse (or touch-emulated mouse).
- Correct placements snap and lock.
- After assembly, a targeting drill unlocks.
- Press `Esc` to exit full screen.

## Asset customization
Add optional images in `bomber/assets/`:
- `bombsight_panel.png`
- `map_bg.png`

If files are missing, built-in placeholder drawings are used.
